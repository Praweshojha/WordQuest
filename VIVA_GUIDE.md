# Viva Guide — WordQuest

This guide contains common viva (oral examination) questions related to the core concepts used in your Java mini-project.

### Q: What is a Class?
**A:** A class is a blueprint or template from which objects are created. In this project, `Player.java` is a class that defines what attributes (id, name) a player has.

### Q: What is an Object?
**A:** An object is an instance of a class. When a user types their name and clicks continue, we create a `new Player("Prawesh")` object.

### Q: What is a Constructor?
**A:** A constructor is a special method used to initialize objects. It has the same name as the class and no return type.

### Q: What is Inheritance?
**A:** Inheritance is a mechanism where a new class inherits properties and methods from an existing class. In WordQuest, `UnscrambleGame` inherits from `GameMode`.

### Q: What is Polymorphism?
**A:** Polymorphism means "many forms." It allows us to perform a single action in different ways. For example, calling `start()` on a `GameMode` reference will execute the specific start logic for Unscramble, Word Quiz, or Hangman depending on the actual object.

### Q: What is Encapsulation?
**A:** Encapsulation is the wrapping of data (variables) and code acting on the data (methods) together as a single unit. We use `private` variables in `Score.java` and access them via public getters and setters.

### Q: What is an Interface or Abstract Class?
**A:** An abstract class is a restricted class that cannot be used to create objects (to access it, it must be inherited). `GameMode` is abstract because it forces child classes to implement `isGameOver()`.

### Q: What is JDBC?
**A:** JDBC stands for Java Database Connectivity. It is an API that allows Java applications to interact with relational databases (like SQLite in our case).

### Q: What is SQLite?
**A:** SQLite is a C-language library that implements a small, fast, self-contained, high-reliability SQL database engine. It doesn't require a separate server process.

### Q: What is PreparedStatement?
**A:** A `PreparedStatement` is a feature of JDBC that allows us to execute parameterized SQL queries. It prevents SQL injection attacks. Used in `PlayerDAO.java`.

### Q: What is ResultSet?
**A:** A `ResultSet` is a table of data representing a database result set, which is usually generated by executing a statement that queries the database.

### Q: Why use Swing?
**A:** Swing is a built-in GUI widget toolkit for Java. It provides components like buttons, text fields, and panels without needing third-party libraries.

### Q: Where is File Handling used?
**A:** It is used in `WordFileManager.java` to read words and questions from `.txt` files, and in `ScoreFileManager.java` to export history.

### Q: Where are Arrays used?
**A:** A 2D array (`char[][] grid`) is used in `WordSearchGame.java` to represent the letter grid.

### Q: Where are Strings used?
**A:** Strings are used everywhere, primarily to represent text, player names, and database queries.

### Q: Where are Loops used?
**A:** Loops (`for`, `while`) are used heavily, for example, generating the Word Search grid, or reading file lines until `null` is returned.

### Q: How does the scoring system work?
**A:** The score is determined by the difficulty (100, 150, 200 points per correct answer) and calculated dynamically inside the `GameUtil` and `GameMode` subclasses.

### Q: How does the timer work?
**A:** The `TimedChallengePanel` uses `javax.swing.Timer`, which executes an action every 1000 milliseconds (1 second) to decrement the time without blocking the UI thread.

### Q: How does the leaderboard work?
**A:** The `ScoreDAO` queries the SQLite database using an `ORDER BY score DESC LIMIT 50` SQL query. The results are loaded into a `JTable` model.

### Q: Why did you choose this project?
**A:** Because it practically demonstrates all core Java concepts (OOP, GUI, JDBC, File I/O) in a fun, interactive way rather than just a boring management system.

### Q: Why is this a Java project?
**A:** Because Java is strongly typed, object-oriented, platform-independent, and provides excellent built-in libraries for UI and Database access, making it ideal for desktop applications.
